# 🛒 Electronic Device Shopping Cart

## 📌 Project Description

This project implements a fully object-oriented Electronic Device Store system in Python.

It demonstrates:

- Inheritance
- Polymorphism
- Encapsulation
- Exception Handling
- Modular Architecture
- Shopping Cart Logic
- Automatic Discount System
